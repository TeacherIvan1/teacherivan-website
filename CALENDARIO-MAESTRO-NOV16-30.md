## 🛠️ Instrucciones de Publicación Automática o Manual

1. **Auto-Publicación con sau / Playwright:**
   - Ejecutá `npm run campaign:publish` dentro de `./media-pipeline/`.
   - El script leerá cada carpeta y su `post-manifest.json` para despachar a las redes configuradas.
2. **Publicación Manual Directa:**
   - Abrí la carpeta correspondiente al día actual.
   - Usá el archivo de video (`.mp4`) o las imágenes (`slide-*.png`).
   - Copiá y pegá el texto optimizado desde `copy-paste-captions.md`.
